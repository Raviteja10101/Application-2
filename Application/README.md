# Study Focus MVP

Expo + React Native + TypeScript implementation based on the five supplied screen prototypes.

## Run

```bash
npm install
npx expo start
```

Press **w** to open the web preview, or scan the QR code with Expo Go on Android.

Routes:
- / Study Ledger
- /focus Focus Canvas
- /diary Session Diary
- /sessions Session Directory
- /create-session Create New Session
